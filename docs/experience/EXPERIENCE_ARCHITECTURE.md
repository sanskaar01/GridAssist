# EXPERIENCE ARCHITECTURE SPECIFICATION
**GridAssist Operations Theater — Experience Architecture Layer**

---

## 1. Executive Summary & Purpose

The **Experience Architecture Layer** bridges the gap between **System Architecture** (backend graph algorithms, database models) and **Rendering Code** (canvas paths, CSS keyframes, particle formulas).

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ TRADITIONAL LAYER GAP (PREVIOUS DRIFT):                                    │
│ System Architecture (Graph Engine) ────► Canvas Rendering (Particles/Lines) │
│ [MISSING EXPERIENCE LAYER: No narrative pacing, camera focus, or suspense]  │
├─────────────────────────────────────────────────────────────────────────────┤
│ REFINED EXPERIENCE LAYER (PHASE 2 ARCHITECTURE):                           │
│ System Architecture ──► EXPERIENCE ARCHITECTURE ──► Choreography ──► Render │
│ • Cinematic Scene Sequencing   • Visual Attention Mapping                   │
│ • Camera Movement Language     • Information Disclosure Pacing               │
└─────────────────────────────────────────────────────────────────────────────┘
```

Rather than jumping directly from database state changes to drawing lines on a canvas, the Experience Architecture defines **how an evaluator experiences the grid in real time**.

---

## 2. The Core Principle: "SHOW FIRST, EXPLAIN SECOND"

GridAssist operates on a strict visual hierarchy:
1. **The Visual Event Happens First:** Conductor breaks, particle flows halt, radial darkness propagates, and the AI graph traversal pulse travels upstream.
2. **The Evaluator Observes the Event Visually:** Without reading any text or documentation, the evaluator understands *where* power was lost and *which* branch failed.
3. **The Explanation Arrives Second:** Only after the visual choreography completes does the compact Mission Control briefing HUD slide in to explain *why* the AI isolated this exact span or rejected a sensor anomaly.

## 3. The 4 Stages of Evaluator Emotional Progression

Every scenario demonstration guides the evaluator through four distinct emotional stages:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. BASELINE STABILITY (0 - 5s):                                             │
│    • Evaluator sees a massive 47-node connected electrical grid.            │
│    • Green power particles flow smoothly. Instill confidence in baseline.  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. PHYSICAL DISRUPTIVE EVENT (5 - 15s):                                     │
│    • Telemetry arrives. A line flashes amber; downstream poles turn dark.   │
│    • Particles halt abruptly. Instill immediate visual clarity & tension.   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3. ALGORITHMIC DEDUCTION (15 - 35s):                                        │
│    • Camera pans smoothly to focus on the fault frontier span.              │
│    • AI graph pulse sweeps upstream. Decision card slides out softly.       │
│    • Instill intellectual awe at the AI's deterministic reasoning.          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. SATISFYING RESOLUTION (35 - 60s):                                        │
│    • Field repair crew marker arrives. Power restoration telemetry arrives.  │
│    • Nodes turn green sequentially; power particles resume floating.        │
│    • Instill complete operational trust and closure.                        │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 4. Experience Subsystem Architecture

The Experience Layer manages 6 coordinated narrative subsystems:
- **`ScenarioChoreography`:** Frame-by-frame script timing for every event stage.
- **`CameraLanguage`:** Pan, zoom, and focus matrix movements targeting specific assets.
- **`VisualAttentionModel`:** Selective dimming (15% opacity on non-affected branches) to force eye focus.
- **`UIInformationHierarchy`:** Progressive disclosure of panels (Queue, Decision Card, Briefing).
- **`MotionLanguage`:** Physical motion curves communicating speed, mass, and tension.
- **`ScenarioCinematography`:** Camera framing, depth-of-field blur simulation, and lighting.
