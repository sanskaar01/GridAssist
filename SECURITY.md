# SECURITY POLICY

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within GridAssist, please do NOT create a public issue.

Instead, please email security concerns to **sanskaar01@users.noreply.github.com**. All security vulnerabilities will be promptly addressed.
