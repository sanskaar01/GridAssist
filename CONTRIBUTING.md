# CONTRIBUTING TO GRIDASSIST

Thank you for your interest in contributing to **GridAssist**!

## How to Contribute

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Clone & Setup:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/GridAssist.git
   cd GridAssist
   ```
3. **Create a Feature Branch:**
   ```bash
   git checkout -b feat/my-new-feature
   ```
4. **Development Rules:**
   - Always run `npm run typecheck` in `/backend` and `/frontend` before committing.
   - Do NOT bypass production telemetry or localization APIs.
   - Follow SCADA visual tokens (`#070A0F` space, `#10B981` live green, `#EF4444` fault glow).
5. **Submit a Pull Request:** Open a PR targeting `main` with a clear explanation of changes.
